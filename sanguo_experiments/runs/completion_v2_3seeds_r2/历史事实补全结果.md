# v2 历史缺失事实补全结果

## 数据与实验协议

从 v2 原外推训练集的 574 条四元组构造一个同时间片补全任务。固定划分种子为 20261110，按同一时间、同一对实体分组，将双向记录与该对实体的不同关系一起留出。得到 460 条观测事实、57 条验证事实和 57 条测试事实，约为 8∶1∶1。划分保留原训练中的 104 个时间片，以及所有原本出现的实体与关系。验证和测试各分布于 32 个时间片。候选范围沿用 v2 映射的 422 个实体和 15 个关系。

两种模型均针对同时间片补全重新训练。每轮在 70 个有至少两个观测组的时间片中，各临时遮蔽一组观测事实作为训练目标。编码器可读取最多两个更早的观测时间片和当前时间片剩余的观测边。TiRGN 的全局历史词表使用严格早于查询的观测事实。频率基线使用截至查询时间的观测事实。固定留出的验证和测试事实均不进入图输入、训练目标或历史词表。

两模型各用随机种子 42、43、44 在 CPU 上训练 20 轮，按验证集实体 filtered MRR 选最早达到最高分的权重。六份权重及其 SHA256 固定后，才写出并读取最终补全测试标签。测试计入 57 条事实的头、尾实体方向以及原、逆关系方向。排序沿用得分降序、同分按候选编号升序。Filtered 排名按当前时间的其他已知答案进行评估侧过滤。

## 留出测试结果

表中神经模型数值为三个种子的均值 ± 样本标准差。频率基线是确定性算法。

| 方法 | 实体 Filtered MRR | 实体 Hits@1 | 实体 Hits@3 | 实体 Hits@10 |
| --- | ---: | ---: | ---: | ---: |
| RE-GCN | 0.1597 ± 0.0431 | 0.0731 ± 0.0308 | 0.1784 ± 0.0506 | 0.3450 ± 0.1047 |
| TiRGN | 0.2174 ± 0.0177 | 0.1111 ± 0.0051 | 0.2515 ± 0.0332 | 0.4357 ± 0.0616 |
| 观测频率 | 0.2448 | 0.1491 | 0.2982 | 0.3684 |

| 方法 | 关系 Filtered MRR | 关系 Hits@1 | 关系 Hits@3 | 关系 Hits@10 |
| --- | ---: | ---: | ---: | ---: |
| RE-GCN | 0.2711 ± 0.0207 | 0.1023 ± 0.0221 | 0.2924 ± 0.0396 | 0.7164 ± 0.0221 |
| TiRGN | 0.2825 ± 0.0482 | 0.1257 ± 0.0415 | 0.3041 ± 0.0704 | 0.6637 ± 0.0442 |
| 观测频率 | 0.2846 | 0.1579 | 0.2632 | 0.5702 |

频率基线在本次内推的实体和关系 MRR 均最高。TiRGN 的实体 Hits@10 最高，RE-GCN 的关系 Hits@10 最高。最终测试只有 57 条事实，本结果限于当前数据、遮蔽划分及训练配置。外推实验的时间切分和输入边界不同，结果单独报告。[外推实验对照](../formal_v2_3seeds_r1/实验对照结果.md)

## CPU 推理计时

每种方法先跑一次完整测试，再计时三次相同的 32 批时间片查询。计时从构造查询所需输入到输出候选排序，包含神经模型的图构造或频率基线的计数，权重加载、启动和评估指标统计在计时范围外。每个种子先取三次耗时的中位数，再除以批数。神经模型报告三个种子的中位数。各方法串行运行，在 WSL CPU 环境下设置两个线程。

| 方法 | 每时间片批次耗时 |
| --- | ---: |
| RE-GCN | 5.611 ms |
| TiRGN | 7.725 ms |
| 观测频率 | 0.986 ms |

本机本次测量中，RE-GCN 每批用时少于 TiRGN，频率基线用时最少。网页请求、WSL 通信和浏览器渲染需另行计时。
