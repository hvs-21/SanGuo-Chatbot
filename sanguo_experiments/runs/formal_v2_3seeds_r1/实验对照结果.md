# v2 时序知识图谱模型对照结果

在 v2 全文复核版上完成 TiRGN、RE-GCN 和历史频率基线的单步外推对照。两模型的最终测试实体 MRR 均超过频率基线，均值接近，三个种子的波动大于两模型的均值差。关系预测中，频率基线的 Hits@10 高于两种模型。

## 数据与协议

训练 574 条，验证 29 条，最终测试 46 条。训练与验证使用 v2 的去重和标注复核结果。测试使用原协议固定的时间 115–126 留出集。模型训练目录在训练期间只包含 train 与 valid。生成的 TiRGN 历史缓存核对了时间边界。

每个模型以 42、43、44 三个随机种子在 CPU 训练 20 轮，每轮验证，取验证 filtered entity MRR 最高且最早的权重。验证后锁定配置和六份权重，再加载最终测试。每次先预测目标时间片，再把该片真实记录加入后续历史。频率基线使用严格更早的事实，根据查询键计数，其次用关系或全局频率。所有方法采用同分按候选编号升序、同一时刻内过滤其他已知答案的规则。实体包含头与尾两个方向，关系包含原关系及逆关系。

## 最终测试结果

神经模型数值为三种子的均值 ± 样本标准差。基线为确定性算法。

| 方法 | 实体 Filtered MRR | 实体 Hits@1 | 实体 Hits@3 | 实体 Hits@10 |
| --- | ---: | ---: | ---: | ---: |
| TiRGN | 0.1378 ± 0.0378 | 0.0833 ± 0.0490 | 0.1558 ± 0.0226 | 0.2464 ± 0.0382 |
| RE-GCN | 0.1355 ± 0.0280 | 0.0580 ± 0.0314 | 0.1812 ± 0.0349 | 0.2790 ± 0.0126 |
| 历史频率 | 0.0401 | 0.0217 | 0.0326 | 0.0652 |

| 方法 | 关系 Filtered MRR | 关系 Hits@1 | 关系 Hits@3 | 关系 Hits@10 |
| --- | ---: | ---: | ---: | ---: |
| TiRGN | 0.2544 ± 0.0223 | 0.0942 ± 0.0332 | 0.3225 ± 0.0314 | 0.5580 ± 0.0599 |
| RE-GCN | 0.2468 ± 0.0266 | 0.0978 ± 0.0326 | 0.2971 ± 0.0599 | 0.5362 ± 0.0274 |
| 历史频率 | 0.2232 | 0.0761 | 0.2174 | 0.6522 |

模型的验证实体 Filtered MRR 均值分别为 TiRGN 0.1343、RE-GCN 0.1551，频率基线为 0.0805。验证与测试各指标、raw 排名、每种子的分数和权重摘要见 [valid_results.json](valid_results.json) 与 [test_results.json](test_results.json)。

## 结果边界

测试事实只有 46 条，模型结果受随机种子和数据覆盖影响。该实验支持两种模型相对当前频率基线的实体排名改善。当前结果不足以判定两种模型哪一个整体更优，也无法将差异归因于 v2 的数据修订。验证集发生过修订，先导与本轮数字不能直接作前后效果对照。

原实验协议记录了早期冒烟测试曾自动接触原测试划分。该次结果用于链路核对。本轮沿用固定划分，训练期间只用 train、valid，最终使用验证选出的权重评估。页面展示 seed 42 的验证预测案例，与本报告最终测试分开。

## 复现

在 WSL 的 `sanguo_experiments` 目录，使用现有 PyTorch 2.1.0 与 DGL 1.1.3 环境运行：

```bash
export DGLBACKEND=pytorch CUDA_VISIBLE_DEVICES=-1 OMP_NUM_THREADS=2 MKL_NUM_THREADS=2
python -B -u train_formal.py --run-name formal_v2_replay
python -B -u evaluate_formal.py --run-dir runs/formal_v2_replay --split valid
python -B -u evaluate_formal.py --run-dir runs/formal_v2_replay --split test
```

本次实际输入、代码副本、配置及摘要见 [protocol.json](protocol.json)，最终测试时固定的权重见 [test_release.json](test_release.json)。每个 `seed*/` 内有训练命令、日志、权重和评估记录。首次运行中，v2 源数据用空格分列，原模型要求制表符。成功运行的预处理只转换了实验副本的分隔符，并校验四元组内容一致。
