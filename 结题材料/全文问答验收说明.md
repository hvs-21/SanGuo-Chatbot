# 全文问答验收

## 题单与判定

开发前固定 30 道题和相应的事实编号、原文章节或行号，保存题单与 SHA256。旧版网页查询的逐题响应也已保留。题目包括 20 道原文可回答的题、5 道只应展示线索的题、3 道范围外的题、2 道需要原文纠正前提的题。开发过程中使用该题单定位问题，因此成绩反映本题单的功能验收结果。[封存题](全文问答封存题.json) · [旧版逐题基线](全文问答开发前基线.json)

验收脚本通过已启动的网页接口发问，逐题记录实际答案、结论类别、引用及失败原因。答复需包含预期信息，引用的事实编号需对应已复核记录。直接引用全文时，脚本核对章节、行号和引文与底本一致，并检查引用范围与对应题目相符。对只应提供线索的题，还要求明确说明结论无法确认。[逐题验收结果](全文问答验收结果.json)

## 结果

| 题目类别 | 旧版通过 | 新版通过 | 新版门槛 |
| --- | ---: | ---: | ---: |
| 原文可回答 | 8/20 | 20/20 | 至少 16 道 |
| 只提供相关线索 | 0/5 | 5/5 | 5 道 |
| 范围外 | 3/3 | 3/3 | 3 道 |
| 原文纠正前提 | 0/2 | 2/2 | 2 道 |

验收环境为 Windows 本机，网页以无 API 密钥模式运行。用户原问“曹操杀了刘备吗”另作开发验证。网页自动定位第 85 回的第 14986–14991 行及第 15029–15034 行，说明刘备在永安宫染病后去世。独立的基础验收仍通过 26 道题和 28 个模型预测案例。

## 回答边界

事实表优先。事实不足时，系统使用人物别名、章内称谓和事件词匹配全文。当前全文直接作答覆盖部分人物别称和死亡情节的时间、经过、地点、年龄与有明确原文依据的前提纠正。其他问法可能返回相关段落或提示资料不足。线索不作为事实证据发送给千问。此题单的通过率不能代表任意全书问题的准确率。

## 复跑

启动服务后，从软件目录运行以下命令，将端口替换为启动窗口显示的端口。

```powershell
python -B -X utf8 .\verify_fulltext_qa.py --port 8765
```
